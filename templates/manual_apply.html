💡 Tips
• Paste a URL that is already in Matched — the Tracker opens that card automatically.
• Submit with Applied to mark an existing Tracker card applied (notes/timeline stay).
• Optional Job title / Company / Location are saved on the Tracker card (works with Save Link Only). Later scrape or Fetch job details will not overwrite a field you typed unless you left it blank.
• Optional Recommended by AI agent tags the Tracker card (Claude / Cursor / Gemini / GPT). Agent-recommended cards get Fetch job details (scrape only, no AI).
• Save Link Only: no Chrome needed; card shows AI pending until you click Run AI or Fetch job details on Tracker.
• Scrape & Log: opens the job page in debug Chrome, saves details, and runs AI. LinkedIn uses the /jobs/view/ID page (not a 24h search). If the URL is already a link-only Tracker card, this refreshes it in place. If Indeed blocks or Chrome is missing, a new URL is still saved as a stub.
• LinkedIn: https://www.linkedin.com/jobs/view/JOB_ID/
• Indeed: https://de.indeed.com/viewjob?jk=JOB_KEY
• Other sites: paste the job detail URL — main content is extracted automatically.
• You can also run from the terminal:
  python src/scrapers/manual_apply_scraper.py "URL1" "URL2"
  python src/scrapers/manual_apply_scraper.py --link-only "URL1"
  python src/scrapers/manual_apply_scraper.py --status applied "URL1"
  python src/scrapers/manual_apply_scraper.py --file my_urls.txt
