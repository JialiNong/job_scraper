How logging works
  • Scrape & Log opens the job page in debug Chrome, saves the details and runs AI. LinkedIn uses the /jobs/view/ID page. If the URL is already a link-only Tracker card, this refreshes it in place. If Indeed blocks or Chrome is down, a new URL is still saved, and you see a warning.
  • Save Link Only needs no Chrome. The card waits for AI until you click Run AI or Fetch job details on the Tracker.
  • Default status is Not Applied. Switch to Applied when you already applied; notes and timeline on an existing card stay.
  • Job title / Company / Location are saved on the Tracker card (also with Save Link Only). A later scrape only fills fields you left blank.
  • Recommended by AI agent tags the card (Claude, Cursor, Gemini, GPT). Agent-recommended cards get Fetch job details (scrape only, no AI).
  • URL formats: LinkedIn https://www.linkedin.com/jobs/view/JOB_ID/, Indeed https://de.indeed.com/viewjob?jk=JOB_KEY, other sites: the job detail URL.

From the terminal:

python src/scrapers/manual_apply_scraper.py "URL1" "URL2"
python src/scrapers/manual_apply_scraper.py --link-only "URL1"
python src/scrapers/manual_apply_scraper.py --status applied "URL1"
python src/scrapers/manual_apply_scraper.py --file my_urls.txt
